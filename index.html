The glossary

Ten terms from software, design, business and language. Each entry gives a definition in English, followed by an example in context.

IDE

Integrated Development Environment. One application that brings a programmer’s tools together: a code editor, a compiler or interpreter, a debugger and a file browser. It is where most software is written and tested.

In use “She ran the tests inside her IDE before pushing the code.”

Webhooks

Messages that one system sends to another automatically when an event happens. Instead of checking for updates again and again, the receiving service is notified the moment something changes.

In use “A webhook tells the delivery service that an order has been paid.”

UX Writer

The person who writes the words inside a product: button labels, error messages, form fields, empty states and microcopy. Their work makes an interface clear, calm and easy to follow.

In use “The UX writer changed ‘Submit’ to ‘Save changes’ so the result was obvious.”

Workloads

The amount of work that a system, a team or a person has to carry. In computing, it usually means the applications, services and tasks running on a server or in the cloud.

In use “The company moved its heaviest workloads to the cloud.”

From scratch

An expression used when something is started or made from the very beginning, without using anything that already exists. In cooking, in building and in software, doing something from scratch means beginning with the basic materials or a blank page.

In use “They built the whole app from scratch instead of adapting an existing template.”

Business Stakeholders

The people and groups with an interest in a project and in what it achieves: clients, managers, employees, users and investors. They may not build the product, but they are affected by its decisions.

In use “The team showed the prototype to the business stakeholders before development began.”

GUI

Graphical User Interface. The visual layer of a program, operated with a mouse, a finger or a stylus: windows, icons, menus, buttons and pointers. It replaced typed commands as the main way to use a computer.

In use “The 1984 Macintosh helped make the GUI familiar to a wide public.”

VUI

Voice User Interface. A system that is operated by speaking rather than touching a screen. It listens for a request, interprets it and answers aloud.

In use “A VUI lets you ask a speaker for the weather without opening an app.”

Time Markers

Words and phrases that place an action in time: yesterday, now, in 2026, after lunch, last week. They help the listener or reader understand when something happens.

In use “Use time markers such as ‘last night’ with the past simple.”

Breadcrumbs

A small trail that shows where you are inside a website and how you reached that page, for example Home / Courses / English. It gives users a clear way to move back up a level.

In use “The breadcrumbs showed that she was three pages into the course.”
